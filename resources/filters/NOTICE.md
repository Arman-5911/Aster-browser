# Bundled filter lists

EasyPrivacy and EasyList are by **The EasyList authors (https://easylist.to/)**.
Original lists: https://easylist.to/easylist/easyprivacy.txt and https://easylist.to/easylist/easylist.txt.
The supplied text lists are unmodified. Retrieval time and SHA-256 hashes are in metadata.json.

These lists are distributed under Creative Commons Attribution-ShareAlike 3.0 Unported:
https://creativecommons.org/licenses/by-sa/3.0/ . The upstream dual-license notice is
https://easylist.to/pages/licence.html . The generated binary indexes are derived from
these lists and are supplied under the same CC BY-SA 3.0 license. Complete original
rule text accompanies the indexes.

The Ghostery adblocker library is MPL-2.0; its source and license are at
https://github.com/ghostery/adblocker . No library source modifications are made.
These lists are used for network matching only; their cosmetic rules and scriptlets are not injected. Aster separately supplies a small YouTube player compatibility script in src/preload/youtube.ts.

Updating lists is an explicit developer action (`npm run filters:update`). There is
no runtime list fetch, telemetry upload or browsing-data submission.
